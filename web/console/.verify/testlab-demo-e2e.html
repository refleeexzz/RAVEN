Break it yourself

Real chaos needs kubectl access, so it can't be a browser button — copy these and watch the effects live.

Kill every worker mid-load

kubectl -n raven delete pod -l app=worker --force --grace-period=0

Run a mini load test first, then fire this. Kubernetes restarts the pods, workers re-join, and in-flight jobs get retried — watch the Workers page and the load-test counters recover.

Scale the worker pool

kubectl -n raven scale deployment worker --replicas=10

Run the load test again after scaling — throughput (jobs/s) should climb. Watch the worker count on the Workers page.
